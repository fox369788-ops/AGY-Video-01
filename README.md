## 🚀 核心特色
1. **ASR 語音辨識 + 物理聲學邊界校正 (-30dB)**：結合 Faster-Whisper 與 FFmpeg 聲學偵測，防止模型跨靜音延伸時間戳。
2. **紅框標註像素自動分析 (R-G > 100)**：自動捕捉 ZoomIt 紅框、紅圈、箭頭等視覺標註，智慧判斷正式 Take。
3. **標註即點選 + 句中畫框去空白**：圈出按鈕即瞬切至載入完成畫面；自動剔除畫框時的安靜等待。
4. **0.2 ~ 0.3s 極速自然呼吸間隔**：維持明快節奏且不吃字。
5. **單詞級字幕重算與同音錯字校正**：依據單詞時間戳自動拆分跨片段字幕，並套用專有名詞校正庫。
6. **FFmpeg 單管線幀級剪輯與硬字幕烙印**：微軟正黑體白字黑底條，免播放器外掛字幕即可直接播放。
